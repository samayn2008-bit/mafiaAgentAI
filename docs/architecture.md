# Implemented architecture
Python/Pydantic contracts → recipient-specific observations → async agent interface → validation → deterministic engine → classified ordered events → public JSONL replay.
A five-player mock runner implements night investigation/kill, dawn, bounded discussion, voting, elimination and win detection. One Mafia, one Detective, three Citizens. Night first; investigation resolves before kill; self-targets forbidden; ties eliminate lowest agent ID; roles hidden on elimination by default. Votes are public as submitted. Seed controls role assignment. Each cycle removes at least one player, guaranteeing termination.
The runner uses GameConfig defaults; loading backend/data/game_config.json is a future integration task. Unsupported starter rule variants are rejected. The engine is an internal component; no action API exists yet. The orchestrator schedules each eligible action once; external commands, phase transition guards, durable execution recovery and duplicate submission protection remain pending.
Failure handling uses a deterministic legal fallback after one failed or timed-out call; diagnostics are inspector-classified. Cancellation propagates. Public event IDs may have gaps because private events share the canonical sequence. Replay validates monotonic unique IDs and one game ID; it does not yet reconstruct authoritative state.
Implemented API: GET /health only. Frontend: launchable status shell and named placeholders. No WebSocket, Inspector, real LLM, Mafia planning chat, snapshot persistence, typed event-payload union, generated TS contracts, voice or 3D behavior yet.
Agent intelligence files belong to P1 and are placeholders except the shared Protocol. MockAgent lives in orchestration to avoid depending on P1 work.
